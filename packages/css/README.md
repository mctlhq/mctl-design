# @mctlhq/css

MCTL CSS: the theme variables (`theme.css`), global and prose styles, the
Telegram Mini App palette (`telegram.css`), a Tailwind v3 preset
(`@mctlhq/css/tailwind-preset`) and a Tailwind v4 theme (`tailwind.css`).

```css
@import '@mctlhq/css/theme.css';
@import '@mctlhq/css/global.css';
```

For product apps, prefer the pinned CDN copy at `https://ui.mctl.ai/<version>/`.
Both routes, the Tailwind setup and versioning are in the
[repository README](https://github.com/mctlhq/mctl-design#readme).
