# @mctlhq/ui

MCTL Vue 3 components (`MButton`, `MModal`, `MTabs`, …). Needs Vue 3.5.

```ts
import '@mctlhq/ui/style.css';
import { MButton } from '@mctlhq/ui';
```

`style.css` defines no variables: load the theme first (`mctl.css` from the CDN,
or `@mctlhq/css/theme.css`), or the components render unstyled. The `MTg*`
components need only `@mctlhq/css/telegram.css`.

The component list, live examples and setup are in the
[repository README](https://github.com/mctlhq/mctl-design#readme) and at
[ui.mctl.ai](https://ui.mctl.ai).
