# @mctlhq/tokens

MCTL design tokens: colors, surfaces, accents, typography, spacing, motion.

```ts
import { color, surface, accent } from '@mctlhq/tokens';
```

Also published as `@mctlhq/tokens/tokens.css` (CSS variables),
`@mctlhq/tokens/tokens.json` and `@mctlhq/tokens/tokens.dtcg.json` (W3C Design
Tokens, for Style Dictionary, Terrazzo and Tokens Studio).

Installation, the CDN alternative and versioning are in the
[repository README](https://github.com/mctlhq/mctl-design#readme).
